⚠️  REQUISITO IMPORTANTE ANTES DE EJECUTAR LA APP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Esta aplicación (LibreriaCRUD.exe) se conecta a una base de datos
MySQL local. Para que funcione correctamente DEBES tener instalado
y corriendo XAMPP antes de abrirla.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PASOS PARA EJECUTAR LA APP (en orden)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASO 1 – Instalar XAMPP (si no lo tienes)
  Descárgalo gratis en: https://www.apachefriends.org
  Instálalo con las opciones por defecto.

PASO 2 – Iniciar MySQL en XAMPP
  1. Abre XAMPP Control Panel
  2. Haz clic en START en la fila de MySQL
  3. Espera a que el botón se ponga en verde

PASO 3 – Importar la base de datos
  1. Abre tu navegador y entra a: http://localhost/phpmyadmin
  2. Haz clic en "Importar" en el menú superior
  3. Selecciona el archivo: database/libreria.sql
  4. Haz clic en "Continuar"
  5. Verás la base de datos "libreria_db" creada con 8 libros de ejemplo

PASO 4 – Ejecutar la aplicación
  Opción A (exe): Abre la carpeta dist/ y ejecuta LibreriaCRUD.exe
  Opción B (python): Abre una terminal en esta carpeta y ejecuta:
    pip install customtkinter mysql-connector-python
    python app.py

PROBLEMAS FRECUENTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ❌ "Can't connect to MySQL"
     → Verifica que MySQL esté iniciado en XAMPP (botón verde)

  ❌ "Unknown database libreria_db"
     → Importa el archivo database/libreria.sql en phpMyAdmin

  ❌ La app abre y se cierra inmediatamente
     → MySQL no está corriendo. Inicia XAMPP primero.
